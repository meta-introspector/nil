# n00b_001: Getting Started with Your Nix Development Environment

Welcome, n00b! This tutorial will guide you through the very first steps of using your Nix development environment.

## What is Nix?

Nix is a powerful package manager that makes it easy to create reproducible and isolated development environments. This means that no matter what operating system you're on, or what other software you have installed, your development environment will always be the same.

## Entering Your Development Shell

You've just set up a `flake.nix` file in the `task/` directory. This file defines a specific development environment for your current task.

To enter this development environment, navigate to the `task/` directory in your terminal and run the following command:

```bash
nix develop
```

You should see a message like:

```
Welcome to the task-specific development shell!
Docs are available at path:/data/data/com.termux.nix/files/home/pick-up-nix2/docs
Scripts are available at path:/data/data/com.termux.nix/files/home/pick-up-nix2/scripts
```

This indicates that you are now inside the Nix development shell. The tools and dependencies specified in `task/flake.nix` are now available in your PATH.

## Exiting the Development Shell

To exit the development shell, simply type `exit` or press `Ctrl+D`:

```bash
exit
```

## What's Next?

Now that you know how to enter and exit your development shell, you can start exploring the tools available within it. For this specific task, you have `bash`, `git`, and `shellcheck` at your disposal.
