## Problem

When attempting to lint and test `nixpacks`, the following error occurs:

```
error: unable to download 'https://api.github.com/repos/meta-introspector/nixpacks/commits/feature/CRQ-016-nixify-workflow': HTTP error 422
response body:
{
  "message": "No commit found for SHA: feature/CRQ-016-nixify-workflow",
  "documentation_url": "https://docs.github.com/rest/commits/commits#get-a-commit",
  "status": "422"
}
```

This indicates that the `ref=feature/CRQ-016-nixify-workflow` used in `nixpacks-src.url` is not a valid commit or branch in the `meta-introspector/nixpacks` GitHub repository.
